# Kindle 大字常显天气屏

当前版本是无短时雨情的常显开销优化测试版，地点为揭西河婆。保留当前气温/晴雨、今日温度范围、明后天天气/温度范围/日降水。实际来源仅Open-Meteo，CC BY 4.0署名保留。旧的含雨情版已完整冻结。

## 使用与更新

沿用Kindle中同一本《天气屏》：退出旧网页，再从书中点击“打开天气屏”，进入后点“保持显示”。不需要USB换书；Wi-Fi联网即可，电脑可以关机。页面中的“更新”只更新天气；重新从书中打开会检查程序版本。

主天气首次/手动立即读取，正常自动取数为北京时间00:35、06:35、12:35、18:35。午夜本地换日期，不发天气请求；错误保留最近成功数据及原时间。当前气温是模型当前条件而非气象站实测，日降水是当地日累计。缺测显示横线，零值才显示0。

## 本轮耗电优化及边界

旧保活为176×144、约29.97fps的内嵌视频，且在timeupdate中反复回拨。新保活改为16×16、1fps、60秒的H.264 Baseline纯黑视频，无音轨、无逐帧JS监听、无手动seek，状态检查间隔61秒。分钟雨情读取、每分钟雨情计算和相关绘字已移除。视频是本地数据，不是网络视频流。

这减少额外工作，**不等于已验证月续航或系统深睡**；帧率下降30倍不表示整机功耗下降30倍。浏览器、播放器、无线网络和后台系统仍可能运行。用户报告旧版7小时掉30个百分点，仅按此粗估满电约23小时；30天目标约需降低31倍平均耗电。电量计、旧电池容量、温度和无线环境都需要实测。

真正低功耗常显可以保留墨水画面、让处理器在更新间隔休眠。但本原厂咪咕系统的休眠画面控制、RTC自动唤醒与原生App安装通道尚未验证，不能套用其他Linux Kindle的KUAL或~ds方案。

实机验收：先静置12分钟看是否仍是天气页；再在相近电量/温度/Wi-Fi条件下拔线对比1–2小时。短测不能证明月续航，后续须观察24–48小时是否接近每日3.3个百分点以内。若使用固定USB充电器，则可长期常显且不依赖电脑；机内电池月续航当前无可靠承诺。
