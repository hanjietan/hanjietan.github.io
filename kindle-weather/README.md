# Kindle 大字天气屏

原厂 Kindle X 咪咕版（KFBJWI）的单地点天气屏，地点为揭西河婆（WGS84 23.4394,115.8305，北京时间）。日常天气来自 Open-Meteo，附加短时降水提示来自和风天气。显示当前气温和晴雨、今天最低—最高温，以及明天和后天的温度范围、晴雨及日降水；不显示风、湿度或复杂曲线。

## 使用与数据更新

沿用已安装的《天气屏》：退出旧天气页，从书中重新点击“打开天气屏”，进入后点“保持显示”。Kindle 通过 Wi-Fi 联网即可使用，电脑可关机，不需要 USB 换书。重新打开书中入口用于检查程序更新；页面里的“更新”用于读取天气。

GitHub 保存程序和派生降水提示缓存。Kindle 直接读取公开 Open-Meteo Forecast API，首次/手动立即取数，正常自动取数每6小时一次。读取失败保留最近成功数据和原时间；北京时间午夜只在本地换日期与日卡，不增加气象请求。

当前气温使用 `current.temperature_2m`，标明 `current.time`；它是模型当前条件，不是气象站实测。顶部晴雨使用当前天气码，今天及明后天温度范围按北京时间的完整日期匹配日数据。日降水为当地日累计，包括雨、阵雨和雪的水当量；缺测显示横线，0才表示零值。来源署名保留 Open-Meteo、CC BY 4.0 和和风天气。

## 短时降水提示

和风数据由 GitHub Actions 后台取得，Kindle 只读取公开派生缓存。每5分钟的取数目标和每月最多10,000次的预算护栏保持不变；私钥只在本机私有目录与仓库 Actions Secret，公开程序、缓存和 Kindle 中没有凭据。

新版 schema3 缓存把分钟数据转换为连续的定性预报时段（无雨、雨、雪、未知及近似雨势），不公开原始分钟雨量、提供方summary或账号信息。`runtime/private-qweather/` 必须排除在发布和备份之外。原schema2账本可由下一次成功取数迁移，调用计数不重置。

页面始终保留一行短时预报，根据当前时间自动切换：

- 连续无雨覆盖：例如“未来1小时40分钟无雨”。只报实际剩余覆盖，不将旧两小时预报续成新的两小时。
- 即将降雨：例如“约20分钟后有小雨”；到达时间之前有缺测时不报分钟倒计时。
- 预报当前有雨：显示当前雨势；若之后有明确无雨时段，再显示约多久停雨。
- 缺测、读取失败或过期：“雨情更新中”，不当作无雨。

小雨、中雨、大雨、强降雨表示从五分钟预报量换算的近似短时雨势，并非全天累计雨量等级；“毛毛雨”不能仅凭雨量小推定。雪不套用雨的强度阈值。canvas中保留“短时预报·和风天气”，DOM中保留可点击的来源链接。

Kindle 每5分钟检查缓存、每分钟本地更新倒计时；主天气仍每6小时更新。有效期不超过实际取得后600秒、源更新时间后1800秒，以及缓存原 `validUntil` 和预报窗口末端。重读旧缓存不续期，保留2分钟未来时钟容差。

约5分钟的 GitHub 调度已配置并重新启用；**尚未观察到实际 schedule 事件运行**，不能把手动运行成功当作自动已验证。GitHub Actions可能延迟。新状态界面已发布，真实完整链路的验证状态以 `runtime/qweather-registration/status.json` 为准。

## 冻结与回滚

Meteoblue 自动取数已停用，当前程序不使用其密钥或取数工作流。原账本与缓存保留作审计，不重置、不回退。

- 完整图表版：`runtime/frozen/weather-full-20261108-032139z/weather-full.zip`，SHA256 `6fd4ae84328364de9d3912a14648ee9d72b2148b1e0582e03142d10c240d2e1e`；构建工具另存 `build-support.zip`。GitHub冻结分支 `codex/frozen-weather-full-20261108-032139z`，提交 `b34b67ea5de95b1b82961fec897334baacf0dc48`。
- Meteoblue 大字版：冻结分支 `codex/frozen-simple-meteoblue-20261108-0412z`，提交 `a6a3c2a32a1dcd51b631c58fc40dc9488d087736`；本地 `meteoblue-simple/` 保留原程序。

界面回滚只更新固定程序入口，保留最新账本和缓存；不能将整条活动分支重置到旧提交。恢复旧界面不会自动重新启用已停用的 Meteoblue 取数。

Kindle 继续只保留一个《天气屏》入口；本轮不写入新书、PDF或导航文件，不修改其他设备文件。
